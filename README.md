# Before the Flood

A hand-drawn climate game about one home and 54 years. Eight-year-old Arda has three days and six choices. Those choices decide how far the sea comes into the family home in 2050 and 2080, and you can watch it happen in the same room, on one key.

**Play it in your browser:** https://durakibrahimcem.itch.io/before-the-flood

Made in 52 hours for the GameUp Türkiye climate game hackathon by HP, ICPSD and UNDP, 30 October to 1 November 2026, with COP 31 in Antalya in mind. Focus areas: oceans and seas, climate-resilient cities, zero waste, and climate-focused education.

## The idea

The easy fix is a trap. A seawall works at first: every one of the 252 plans that build one is still dry in 2050. But nobody maintains it while the sea keeps rising, and by 2080 244 of those plans have lost both homes. Not one saves both.

The 25 plans that save both homes are slow ones. All of them replant seagrass and hold neighbourhood meetings, and none of them builds a wall.

The future isn't scripted. It is computed from your plan and the year, and the water is drawn live over Ebru's painted rooms, so holding T runs the same room through 54 years in seconds.

| Plan | Water in the salon in 2080 |
| --- | --- |
| Do nothing | 0.91 m |
| Six seawalls | 1.19 m |
| Best plan: seagrass ×2, meetings ×2, dunes, sorting | 3 cm, and both homes stand |

The coast is fictional and the model is simplified. It shows how choices connect, not what will happen anywhere real. Sea-level curves come from IPCC AR6 data, and the sources are in the game's end screens and the presentation.

## Controls

| Key | Action |
| --- | --- |
| W A S D | Walk |
| E | Interact |
| Tap T | Jump between 2026, 2050 and 2080 |
| Hold T | Run the years, with the mouse or walking keys |
| Esc | Pause and settings, including larger text and calm storm |

## Run it

Download the Windows build from the itch.io page, unzip it, and run `BeforeTheFlood.exe`. The build isn't signed, so Windows may warn you: choose More info, then Run anyway.

To work on the source, install [Godot 4.7.2](https://godotengine.org/), then run these from the repo root:

```bash
tools/gate.sh             # runs every check and test scene
tools/release.sh          # builds the Web and Windows zips into build/release
tools/film.sh out.mp4     # films the trailer from the real game
```

The game is in `game/`. It uses GDScript and the Compatibility renderer, and the Web build is single-threaded.
